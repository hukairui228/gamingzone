# 孤胆车神：雄霸迈阿密 (Gangstar: Miami Vindication — WebGL2 Tribute)

一款致敬 2010 年 Gameloft 经典《孤胆车神：雄霸迈阿密》的浏览器开放世界犯罪动作游戏。
城市、角色、美术、音乐全部由代码实时生成，零外部素材：所有模型、贴图、音效和电台音乐都在浏览器中程序化生成。

## 运行

```bash
npm install
```

```bash
npm run dev
```

打开终端里显示的地址即可。打包：`npm run build`（输出到 `dist/`），或 `npm run build:single` 生成单个 HTML 文件（`dist-single/index.html`，可直接双击打开或托管到任何静态站点）。

## 内容

- **迈阿密**：约 1 km² 的程序化海滨城市：港口区、市中心、小海地、椰林区、南海滩、北海滩，以及跨海大桥连接的珊瑚岛。
- **画面**：HDR + ACES 色调映射、物理天空与动态环境光照、4K 级阴影、实时反射海面、泛光、调色与暗角、氮气径向模糊、昼夜循环（夜晚窗户逐个亮起、路灯点亮）、暴雨与雷电、积水路面。
- **驾驶**：16+ 种载具（Tawny 40o、Grand Detour、D340、Superlative、Sanchez、Yamakasi、Sea-Gar、Sea-Ride 等原版车名）、手刹漂移、氮气、特技跳台（慢镜头）、车损冒烟起火爆炸、轮胎印与烟雾、坠海。
- **战斗**：手枪/冲锋枪/散弹枪/突击步枪/狙击枪/火箭筒/棒球杆/手雷、过肩瞄准、驾车射击、**专注时间（子弹时间）**。
- **城市生态**：遵守红绿灯的交通 AI、人行道行人、受惊逃跑、抢车。
- **通缉系统**：1–5 星，巡逻车包抄撞击、警察下车追捕、4 星以上直升机探照灯，脱离视线即可甩掉。
- **剧情**：18 个任务、5 章原创剧情（强尼、乔伊、贝蒂、LC、罗斯科 vs 克莱夫·可里克），基于原版 IPA 中文台词数据。
- **支线**：出租车载客、街头赛车、漂移挑战、特技跳台、25 枚秘密道具、15 块冲浪板、15 个特殊轮毂、武器商店、医院、安全屋存档。
- **车行改装**：修车、喷漆、底盘氛围灯、引擎三级调校、装甲、氮气，保存爱车。
- **帮派地盘**：阿马达帮、沼泽帮、海滩帮、街头帮，消灭帮派成员触发地盘争夺战。
- **其它**：GPS 小地图导航、可点击设置导航点的大地图、拍照模式（5 种滤镜）、三个程序化生成的电台（迈阿密浪潮 FM）、键鼠 / 手柄 / 触屏全支持、画质四档可调。

## 代码结构

`src/` 下每个模块一个系统：`layout.js`（城市布局与道路图）、`world.js`（程序化建城）、`materials.js`（立面/路面着色器）、`sky.js`（天空、昼夜、天气）、`gfx.js`（渲染与后处理）、`vehicle.js`、`character.js`、`player.js`、`traffic.js`、`peds.js`、`police.js`、`weapons.js`、`missions.js`、`activities.js`、`audio.js`、`hud.js`、`main.js`。
