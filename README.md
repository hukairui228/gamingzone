# 霓虹港湾：街头之王 (Neon Harbor: Streets of Solara Bay)

一款**原创**的浏览器开放世界犯罪动作游戏，致敬 2010 年前后手机上那批"海滨城市 + 开车 + 警匪"的经典玩法。
城市、角色、剧情、美术、音乐全部原创，零外部素材：所有模型、贴图、音效和电台音乐都由代码实时生成。

## 运行

```bash
npm install
```

```bash
npm run dev
```

打开终端里显示的地址即可。打包：`npm run build`（输出到 `dist/`），或 `npm run build:single` 生成单个 HTML 文件（`dist-single/index.html`，可直接双击打开或托管到任何静态站点）。

## 内容

- **太阳湾**：约 1 km² 的程序化海滨城市：金融中心玻璃塔楼、粉彩装饰艺术风海滨酒店与霓虹招牌、棕榈住宅区、集装箱码头与龙门吊、日落海滩，以及跨海大桥连接的珊瑚岛。
- **画面**：HDR + ACES 色调映射、物理天空与动态环境光照、4K 级阴影、实时反射海面、泛光、调色与暗角、氮气径向模糊、昼夜循环（夜晚窗户逐个亮起、路灯点亮）、暴雨与雷电、积水路面。
- **驾驶**：10 种原创车型、手刹漂移、氮气、特技跳台（慢镜头）、车损冒烟起火爆炸、轮胎印与烟雾、坠海。
- **战斗**：手枪/冲锋枪/霰弹枪/步枪/火箭筒/手雷、过肩瞄准、驾车射击、**专注时间（子弹时间）**。
- **城市生态**：遵守红绿灯的交通 AI、人行道行人、受惊逃跑、抢车。
- **通缉系统**：1–5 星，巡逻车包抄撞击、警察下车追捕、4 星以上直升机探照灯，脱离视线即可甩掉。
- **剧情**：8 个原创任务（凯、老萨尔、莉娜 vs 珊瑚帮老大维克斯）。
- **支线**：出租车载客、两条街头赛、漂移挑战、6 个独特特技跳台、25 枚霓虹徽章、枪械店、医院、安全屋存档。
- **车行改装**：修车、喷漆、霓虹底盘灯、引擎三级调校、装甲、氮气，保存爱车。
- **其它**：GPS 小地图导航、可点击设置导航点的大地图、拍照模式（5 种滤镜）、三个程序化生成的电台（合成器浪潮 / 拉丁 / Lo-fi）、键鼠 / 手柄 / 触屏全支持、画质四档可调。

## 代码结构

`src/` 下每个模块一个系统：`layout.js`（城市布局与道路图）、`world.js`（程序化建城）、`materials.js`（立面/路面着色器）、`sky.js`（天空、昼夜、天气）、`gfx.js`（渲染与后处理）、`vehicle.js`、`character.js`、`player.js`、`traffic.js`、`peds.js`、`police.js`、`weapons.js`、`missions.js`、`activities.js`、`audio.js`、`hud.js`、`main.js`。
